## Codebase Patterns
- Tests run with: `pytest test_scoring.py -v` or `pytest test_game.py -v` (pytest 8.4.1, Python 3.10.6)
- No typecheck tool installed (pyright/mypy not available) — skip typecheck step
- Project uses a `.venv` but the system pytest works fine
- `main.py` already contains a working Yahtzee TUI — new modules should complement it
- Scoring functions use `Counter` from `collections` for counting die values
- `game.py` uses category names matching scoring.py functions (e.g., "three_of_a_kind", "small_straight") — NOT the abbreviated names used in main.py ("three_of_kind", "sm_straight")
- `GameState.commit()` raises `ValueError` for unknown category, already committed, or roll_count == 0
- `GameState.scores` maps all 13 category names to `int | None` (None = uncommitted)

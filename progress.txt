## Progress Log — ralph/scoreboard-and-build

## Codebase Patterns
- Project uses `yahtzee/` package for all UI/game components; root-level `.py` files are standalone modules (scoring.py, game.py)
- Textual app is in `yahtzee/app.py`; each modal screen is in its own file under `yahtzee/`
- Tests live at root level: `test_scoring.py`, `test_game.py`
- Run tests: `pytest test_scoring.py test_game.py -v`

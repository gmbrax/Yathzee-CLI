## Codebase Patterns
- DieWidget IDs for inner children use die index to stay globally unique: `id=f"face-{self.die_index}"` — `self.query_one(f"#face-{self.die_index}", Static)` queries within the widget's own subtree
- `Widget.can_focus = True` (class variable) makes a widget keyboard-focusable; CSS `:focus` pseudo-class then controls focus styles
- CSS compound selectors work in Textual: `DieWidget.held:focus { border: double #58a6ff; }` — both `.held` class and `:focus` pseudo-class applied simultaneously
- Tests run with: `pytest test_scoring.py -v` or `pytest test_game.py -v` (pytest 8.4.1, Python 3.10.6)
- No typecheck tool installed (pyright/mypy not available) — skip typecheck step
- Project uses a `.venv` but the system pytest works fine
- `main.py` already contains a working Yahtzee TUI — new modules should complement it
- Scoring functions use `Counter` from `collections` for counting die values
- `game.py` uses category names matching scoring.py functions (e.g., "three_of_a_kind", "small_straight") — NOT the abbreviated names used in main.py ("three_of_kind", "sm_straight")
- `GameState.commit()` raises `ValueError` for unknown category, already committed, or roll_count == 0
- `GameState.scores` maps all 13 category names to `int | None` (None = uncommitted)
- New TUI lives in `yahtzee/` package; `CSS_PATH = "app.tcss"` resolves relative to the app.py file, so place app.tcss in yahtzee/
- Run with `python -m yahtzee` from project root; `TITLE`/`SUB_TITLE` class vars display in the built-in Header widget
- Use `VerticalScroll` as base class for scrollable panel widgets; set `can_focus = False` on the container if only child rows should be focusable
- `color: inherit` in TCSS makes Static children follow parent Widget's color, enabling focus/committed state to cascade cleanly
